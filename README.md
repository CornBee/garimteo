# 갈림터 · GARIMTEO

어느 도시를 키우고, 어느 길을 지킬 것인가. 열두 턴으로 완성하는 작은 세력의 역사.

갈림터는 문명5의 입지·발전·전쟁과 간결한 공간 전략에서 출발한 브라우저 게임입니다. 현재 상태를 모두 공개하고, 명령은 비공개로 동시에 해결합니다.

## 플레이

- 내 지역을 선택해 도시를 개발하거나 병력을 모집합니다.
- 지역 상세의 목적지 버튼 또는 연결된 길을 눌러 이동할 병력을 지정합니다.
- 명령 수첩에서 자원과 병력 배분을 확인한 뒤 **명령 확정**을 누릅니다.
- 마지막 턴에 더 많은 지역을 가진 연맹이 승리합니다.
- 하단의 턴 기록을 눌러 지난 명령과 결과를 복기할 수 있습니다.

**새 원정**에서 5개 지역의 연습, 본게임, 컴퓨터 성향, 기기 공유 2인 대전을 선택합니다. 미라와 로안의 능력치는 같습니다.

## 첫 버전

- 11개 지역 · 14개 길 · 12턴의 고정 지도
- 5개 지역 · 6턴 연습
- 지역 개발, 제한 모집, 병력 분할과 이동
- 길 위 충돌과 다방향 도착을 처리하는 결정론적 전투
- 공개 상태만 입력받는 Web Worker 기반 컴퓨터 상대
- 한 기기에서 명령을 봉인하고 넘겨주는 2인 대전
- 조건을 명시한 계획 미리보기
- 턴별 복기, 관전 화면, 전투·개발 기록
- IndexedDB 자동 저장과 JSON 내보내기·불러오기

## 규칙

매 턴 자원 `4 + 점유 도시 단계 합`을 받습니다. 개발은 0→1에 4, 1→2에 6이 들며 다음 턴부터 수입과 모집 상한을 늘립니다. 병력 한 명은 자원 2, 모집 상한은 각 도시의 턴 시작 개발 단계입니다. 신규 병력도 이번 턴에 움직일 수 있습니다.

각 병력은 한 턴에 한 길만 이동합니다. 같은 길로 마주 오는 병력은 먼저 충돌합니다. 목적지에 도착한 같은 편 병력은 합쳐서 싸웁니다. 양측이 같은 수만큼 소모되고 차이만 남습니다. 아무도 남지 않으면 이전 점유권을 유지합니다. 도시를 빼앗으면 개발 단계도 함께 얻어 다음 턴부터 이용합니다.

미리보기는 **상대가 아무 행동도 하지 않는 가정**입니다. 실제 승리 보장이나 확률이 아닙니다. 도시의 고립으로 수입이 끊기거나 지형에 별도 전투 보너스가 붙지는 않습니다.

## 개발

Node.js 24 이상을 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

Vite가 표시하는 로컬 주소에서 실행합니다. `dist/`가 정적 배포 결과입니다. 상대 경로로 빌드하므로 GitHub Pages의 저장소 하위 경로에서도 작동합니다.

## GitHub Pages

저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다. `main`에 반영하면 테스트·빌드 후 배포됩니다. `codex/first-playable` 브랜치는 테스트와 빌드만 실행합니다. 원격 저장소에 인증할 권한은 별도로 필요합니다.

목표 주소: `https://cornbee.github.io/garimteo/`. 주소가 실제 배포되었는지는 Actions와 Pages 상태에서 확인합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/game.ts` | 지도, 상태, 명령 검증, 동시 판정, 기록 검증 |
| `src/ai.ts` | 공개 상태 기반 후보 생성과 상대 대응 평가 |
| `src/ai.worker.ts` | UI와 분리한 상대 계산 |
| `src/storage.ts` | 로컬 저장과 파일 교환 |
| `src/main.ts` | 지도 조작, 원정 진행, 복기와 메뉴 |
| `src/style.css` | 지도·인터페이스·반응형 표시 |
| `tests/game.test.mjs` | 판정·대칭·보존·기록 재생 검증 |

## 검증과 현재 한계

14개 자동 테스트가 있습니다. 28개 모의 원정에서 판정의 좌우 대칭, 양측 병력 손실, 자원과 개발 범위를 검사합니다. 전체 컴퓨터 대전, 기록 재구성과 변조 거부도 포함합니다. `npm run build`로 TypeScript와 배포 빌드를 확인합니다.

자동 테스트는 게임의 균형이나 실제 플레이의 재미를 증명하지 않습니다. 브라우저 시각 QA와 실제 사람의 플레이 테스트는 별도로 필요합니다. 작은 화면에서는 지도의 글자가 작을 수 있으므로 초기 테스트는 데스크톱을 권장합니다.

온라인 매칭, 계정, 클라우드 저장은 없습니다. 기기 공유 대전은 지인 간 테스트용이며 경쟁전 보안 기능이 아닙니다. 이 브라우저의 저장소를 지우면 내보내지 않은 기록이 사라집니다. 글꼴을 불러올 수 없으면 시스템 글꼴을 사용합니다.

WebMCP를 지원하는 환경에서는 공개 상태 읽기와 명령 초안 배치 도구를 실험적으로 등록합니다. 전용 WebMCP 실행 환경에서의 호출 검증은 아직 수행하지 않았습니다. 게임 플레이에는 필요하지 않습니다.
